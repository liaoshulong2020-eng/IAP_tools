# 发布规则

本目录保存当前可用发布件和发布规则说明。

本机固定发布位置：

- 上位机：`C:\Users\10412\Desktop\ZHLD_CAN_IAP_v1.0\CAN_TOOLS_IAP.exe`
- 烧录码：按项目/芯片/目标单独放置，不与上位机运行目录混放。

GitHub 当前发布目录：

- 上位机：`release/CAN_TOOLS_IAP`
- 烧录码：后续按 `release/firmware/...` 分类保存。

发布原则：

1. 上位机运行文件不放在“烧录码”目录下。
2. 上位机目录不绑定 `259B`、`D版本`、`PFC` 等单一项目名称。
3. 每次只保留最新一套需要现场使用的烧录码。
4. 烧录码文件名必须标出芯片/项目/目标/波特率/用途。
5. JLink 合并烧录文件和在线升级 APP 文件分开命名。
6. 发布前先确认 APP 与 bootloader 的 CAN 波特率一致。

当前建议命名：

- `259B_LLC_V_1_2_0_20260711_125k_JLink烧录.bin`
- `259B_LLC_V_1_2_0_20260711_125k_在线升级.bin`
